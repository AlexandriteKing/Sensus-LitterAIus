# Sensus Litterallis


## Purpose

This repository preserves primary source materials through careful transcription, documentation, and provenance. It is intended to distinguish original source content from later interpretation.

##Scope

This repository is dedicated to preserving primary source materials in their original form. It emphasizes accurate transcription, documentation, provenance, and a clear distinction between source material and interpretive analysis. The goal is to preserve the historical record faithfully while keeping interpretation separate from the source itself.
